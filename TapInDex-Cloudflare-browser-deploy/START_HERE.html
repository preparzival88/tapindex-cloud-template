Set up your private cloud service

Use this page on your computer. It prepares your deployment link and a recovery encryption key. Nothing here creates a Cloudflare service until you open the deployment link and confirm there.

1 · Upload the backend to GitHub

Create a new public repository named tapindex-cloud-template. Upload the extracted contents of the deployment bundle. Its root must contain worker.mjs, package.json and wrangler.jsonc.

Upload only this backend bundle. Keep your Android project, signing files, personal backups and actual keys out of the public repository. The included .env.example contains names, not real secrets.

Create GitHub repository ↗

Read BROWSER_SETUP.md for upload steps and the private-repository alternative.

2 · Prepare the deployment link

Open Cloudflare deployment ↗

Sign in to Cloudflare and GitHub/GitLab. Keep Worker name tapindex-sharing. Enter actual keys only in Cloudflare's secret prompts.

3 · Generate recovery keys for a NEW service

For a fresh installation only. If you already have cloud backups, reuse your saved keys. Replacing an existing key can make those backups unreadable.

Use a password manager or another secure location. The downloaded file contains a secret; do not upload it to GitHub. This page uses your browser's random-number generator and makes no network requests to generate or store keys. Reloading clears the value. Encryption is service-managed, not end-to-end.

4 · Deploy, connect and test

In Cloudflare, enter your Supabase publishable key and both backup values. Use build command npm run build and deploy command npm run deploy. Deployment creates the resources, applies migrations and publishes the service.

Copy the actual Worker HTTPS origin into your Android project's gradle.properties:

Build your beta APK, then test an upload on one phone and a reviewed restore on another. Download the catalog on the replacement phone and restore before enabling its automatic uploads.

No service is deployed and no APK is built by opening this page. Cloudflare may require billing activation for R2. The walkthrough covers privacy checks, troubleshooting and remaining phone tests.

No analytics or automatic uploads. Cloudflare and GitHub/GitLab are external services opened only through the links you choose.
